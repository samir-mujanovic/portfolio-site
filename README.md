# Samir Mujanovic — Ubuntu desktop portfolio

A portfolio site that looks like an Ubuntu desktop. The main window is a terminal: type commands to learn who Samir is, browse projects, certificates, and social links.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Edit your content

All personal content lives in `src/data/profile.ts`:

- bio (`whoami` / `whois`)
- social links
- projects
- certificates
- email

## Commands

| Command | What it does |
| --- | --- |
| `whois` | Who is Samir Mujanovic? |
| `whoami` | First-person intro |
| `social` | Social networks |
| `projects` | Coding projects |
| `certificates` | Certifications |
| `history` | Command history |
| `help` | List commands |
| `email` | Contact |
| `clear` | Clear the terminal |
| `banner` | Show the header |
